# Documentation index

| Folder | Contents |
| --- | --- |
| `product` | Vision, user roles, scope and Phase 1 increments (from the BRD) |
| `architecture` | Guidelines for API, database, events, security, testing, deployment and coding |
| `modules` | One working brief per backend module (from the architecture document, Section 5) |
| `adr` | Architecture decision records ADR-01 to ADR-16 (ADR-16 is proposed, not yet accepted) |
| `decisions` | Open issues and decisions needed, with owners |
| `security` | Malware prevention and agent supply-chain checklist |
| `source-documents` | The BBDA Word documents: 00 documentation index and traceability, 01 BRD, 02 SRS, 03 system architecture, 04 ERD and data model, 05 workflows, plus the two "Agent Based Development" notes that set the agent working method |

The Word documents are the source of truth. Briefs and guidelines here are working summaries; if they differ, the source document wins and the brief must be corrected.
